# 系統操作手冊 (User Manual)

## 1. 成員管理 (Member Management)

### 1.1 新增成員
1.  進入首頁「成員管理」。
2.  點擊右上角 **「+ 新增成員」** 按鈕。
3.  填寫基本資料：
    *   **姓名**：必填。
    *   **性別**：影響家族樹節點顏色 (藍/粉)。
    *   **出生/過世日期**：支援 `YYYY-MM-DD` 格式。若已過世，請勾選「Status: 歿」或填寫過世日期，頭像將自動轉為黑白。
    *   **照片網址**：請參考下方「照片管理」章節。

### 1.2 建立關係
您可以透過兩種方式建立關係：
1.  **父母關係**：在成員編輯視窗中，直接選擇「父親」與「母親」。
2.  **配偶關係**：在成員列表點選該成員，進入編輯模式，在「配偶」欄位選擇對象。

### 1.3 照片管理 (Google Drive 自動化)
本系統支援直接讀取 Google Drive 照片。
1.  將照片上傳至 Google Drive 指定資料夾，檔名需包含成員名字 (如 `.jpg`)。
2.  開啟 Google Sheet 資料庫。
3.  點選上方選單 **「家族樹工具」** -> **「更新照片連結」**。
4.  系統會自動填入連結，回到網頁重新整理即可看到頭像。

## 2. 家族樹操作 (Family Tree Navigation)

### 2.1 瀏覽操作
-   **縮放 (Zoom)**：使用滑鼠滾輪，或點擊右下角的 `+` / `-` 按鈕。
-   **移動 (Pan)**：按住滑鼠左鍵拖曳畫布。
-   **適應視窗 (Fit View)**：點擊右下角的「四向箭頭」圖示，自動將整棵樹縮放至可視範圍。

### 2.2 搜尋成員
1.  點擊左上角的 **搜尋圖示**。
2.  輸入姓名關鍵字。
3.  點選列表中的成員，家族樹會自動飛越並聚焦到該成員節點。

### 2.3 匯出圖片
-   點擊右上角的 **「下載圖片」** 按鈕，系統將當前家族樹存為 PNG 圖檔。

## 3. 沙漏圖檢視 (Hourglass View)

除了全家族圖之外，系統提供了全新的「沙漏圖」模式，協助您專注探索特定人物的家系。

### 3.1 切換視圖模式
- 在「家族樹」頁面頂部，您可以點擊分段切換按鈕，在 **全家族圖** 與 **沙漏圖** 之間自由切換。系統會記住您在該設備上的選擇。

### 3.2 以單一人物為焦點
- 沙漏圖永遠以單一「焦點人物」為中心展開。
- **向上** 會顯示該人物的直系祖先（父母、祖父母、曾祖父母等）。
- **向下** 會顯示該人物的所有血緣後代。
- 您可以透過點擊工具列的 **「上/下代數」** 來調整顯示的世代深度（例如：只顯示 2 代祖先，或顯示所有後代）。

### 3.3 切換與導覽
- **變更焦點**：點擊畫面上任何人物，底部會出現「以此人為焦點」的按鈕。點擊後，該人物將成為新的中心。
- **配偶家系**：點擊配偶旁邊的 **「配偶家系 >」徽章** 進入對方家族。
- **歷史回溯**：點擊工具列的 **「< 返回」** 回到上一個焦點，或點擊頂部麵包屑直接跳轉。

## 4. 多資料源切換與登入 (Multi-Source Auth)

### 4.1 使用不同 PIN 碼切換家族
- 系統支援載入多個 Google Sheet 資料表（例如「己方家系」與「配偶家系」）。
- 在登入畫面輸入不同的 PIN 碼，系統會自動解鎖對應的家族樹資料。
- 每次登入後，系統會自動將資料儲存於瀏覽器以供離線查看；若要切換至另一個家系，請點選右上角「登出 / 上鎖」圖示，然後輸入另一組密碼。

### 4.2 管理員加密小幫手 (Encryption Helper)
如果您有 Master Key (萬用管理員密碼)，可以直接在網頁上產生新的安全密文，而不需要開啟電腦終端機：
1. 進入登入畫面，點選最下方的小字 **「管理員救援通道」**。
2. 找到 **「方案 3：開發者加密小幫手」**。
3. 輸入您想設定的 **新 PIN 碼**，並貼上 Google Sheet 正確的 **發布網址 (CSV格式)**。
4. 點擊「產生安全密文」，系統會即時產出 `eyJ2ZX...` 的字串。
5. 點擊「複製密文」，將其加到程式碼的 `.env` 中並重新部署，所有人就能立刻使用這組新密碼了！

## 5. 壽星月曆與小工具

### 5.1 壽星月曆
- 顯示本月所有壽星及其年齡，右側日曆可點擊查看當日壽星。

### 5.2 親屬計算機
- 透過左側下拉選單選擇親屬關係，自動計算出稱謂（開發中預留）。
