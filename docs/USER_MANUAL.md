# 系統操作手冊 (User Manual)

## 1. 成員管理 (Member Management)

### 1.1 新增成員
1.  進入首頁「成員管理」。
2.  點擊右上角 **「+ 新增成員」** 按鈕。
3.  填寫基本資料：
    *   **姓名**：必填。
    *   **性別**：影響家族樹節點顏色 (藍/粉)。
    *   **出生/過世日期**：支援 `YYYY-MM-DD` 格式。若已過世，請勾選「Status: 歿」或填寫過世日期，頭像將自動轉為黑白。
    *   **照片網址**：請參考下方「照片管理」章節。

### 1.2 建立關係
您可以透過兩種方式建立關係：
1.  **父母關係**：在成員編輯視窗中，直接選擇「父親」與「母親」。
2.  **配偶關係**：在成員列表點選該成員，進入編輯模式，在「配偶」欄位選擇對象。

### 1.3 照片管理 (Google Drive 自動化)
本系統支援直接讀取 Google Drive 照片。
1.  將照片上傳至 Google Drive 指定資料夾，檔名需包含成員名字 (如 `.jpg`)。
2.  開啟 Google Sheet 資料庫。
3.  點選上方選單 **「家族樹工具」** -> **「更新照片連結」**。
4.  系統會自動填入連結，回到網頁重新整理即可看到頭像。

## 2. 家族樹操作 (Family Tree Navigation)

### 2.1 瀏覽操作
-   **縮放 (Zoom)**：使用滑鼠滾輪，或點擊右下角的 `+` / `-` 按鈕。
-   **移動 (Pan)**：按住滑鼠左鍵拖曳畫布。
-   **適應視窗 (Fit View)**：點擊右下角的「四向箭頭」圖示，自動將整棵樹縮放至可視範圍。

### 2.2 搜尋成員
1.  點擊左上角的 **搜尋圖示**。
2.  輸入姓名關鍵字。
3.  點選列表中的成員，家族樹會自動飛越並聚焦到該成員節點。

### 2.3 匯出圖片
-   點擊右上角的 **「下載圖片」** 按鈕，系統將當前家族樹存為 PNG 圖檔。

## 3. 壽星月曆 (Birthday Calendar)

### 3.1 查看壽星
-   進入「壽星月曆」頁面。
-   **左側列表**：顯示本月所有壽星及其年齡。
-   **右側日曆**：以月曆形式呈現，點擊日期可查看當日壽星。

### 3.2 切換月份
-   點擊日曆上方的 `<` 或 `>` 按鈕可切換月份。
-   點擊 **"Today"** 可快速回到當前月份。

## 6. 沙漏圖檢視 (Hourglass View)

除了全家族圖之外，系統提供了全新的「沙漏圖」模式，協助您專注探索特定人物的家系。

### 6.1 切換視圖模式
- 在「家族樹」頁面頂部，您可以點擊分段切換按鈕，在 **全家族圖** 與 **沙漏圖** 之間自由切換。系統會記住您在該設備上的選擇。

### 6.2 以單一人物為焦點
- 沙漏圖永遠以單一「焦點人物」為中心展開。
- **向上** 會顯示該人物的直系祖先（父母、祖父母、曾祖父母等）。
- **向下** 會顯示該人物的所有血緣後代。
- 您可以透過點擊工具列的 **「上/下代數」** 來調整顯示的世代深度（例如：只顯示 2 代祖先，或顯示所有後代）。

### 6.3 切換與導覽 (Navigation)
- **變更焦點**：點擊畫面上任何人物，底部會出現「以此人為焦點」的按鈕。點擊後，該人物將成為新的中心。
- **配偶家系**：配偶只會顯示本人，不會直接展開其家族。若想查看配偶的家系，請點擊配偶旁邊的 **「配偶家系 >」徽章**。
- **更多祖先**：若某位祖先上方還有未顯示的長輩，會出現 **「更多祖先 >」徽章**，點擊即可切換焦點至該祖先。
- **返回與歷史**：您可以點擊工具列的 **「< 返回」** 回到上一個焦點人物，或點擊頂部的 **麵包屑歷史** 直接跳轉到之前的層級。

### 6.4 書籤功能
工具列提供了三個快速書籤，讓您隨時回到主要家系：
- **我的家系**：回到預設的「首頁人物」（可以點擊工具列的「設為首頁」來更改預設人物）。
- **母系**：以目前焦點人物的母親為新焦點，探索母系的家族樹。
- **配偶家系**：若焦點人物有配偶，點擊後即可將焦點切換至其配偶。

### 6.5 折疊與展開
- 若某位人物的後代太多，您可以點擊其下方的 **「[-]」徽章** 將後代折疊起來。
- 折疊後會顯示 **「[+N 後代]」**，再次點擊即可展開。
- 變更工具列的顯示代數會清除您手動的折疊狀態。
